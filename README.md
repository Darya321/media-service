# Упаковано

Учебный медиасервис для малого бизнеса: помогает разобраться в упаковочных материалах, получить предварительный расчёт, сравнить поставщиков и сохранить учебную заявку. Проект собран на Ruby on Rails по утверждённому макету Figma.

Важно: цены, компании, контакты, заявки и подписки в проекте демонстрационные. Сервис не отправляет письма и не передаёт заявки реальным поставщикам.

## Что уже работает

- главная страница в визуальном стиле макета;
- медиа с категориями, публикациями, черновиками и отложенной публикацией;
- каталог упаковочных материалов с характеристиками;
- предварительный калькулятор упаковки;
- каталог и фильтры поставщиков;
- учебная заявка с серверным пересчётом цены;
- локальная подписка без отправки писем;
- защищённая панель управления контентом, каталогом и заявками;
- адаптивные версии для 1440, 1024, 768 и 375 px.

## Требования

- Ruby 4.0.6;
- Bundler;
- SQLite 3;
- современный браузер.

Версии Rails и остальных библиотек зафиксированы в `Gemfile.lock`.

## Первый запуск

Из корня проекта:

```sh
bin/setup --skip-server
bin/rails db:seed
bin/dev
```

Затем откройте [http://127.0.0.1:3000](http://127.0.0.1:3000).

`bin/setup --skip-server` проверит библиотеки, подготовит базу и очистит временные файлы. Повторный `bin/rails db:seed` безопасен: демонстрационные записи обновляются по стабильным адресам и не дублируются.

## Создание администратора

Администратор создаётся только тогда, когда одновременно переданы email и пароль. Пароль должен содержать не менее 12 символов. В zsh можно ввести его без отображения на экране:

```sh
read -s "UPAKOVANO_PASSWORD?Введите пароль администратора: "
echo
ADMIN_EMAIL=admin@example.test ADMIN_PASSWORD="$UPAKOVANO_PASSWORD" bin/rails db:seed
unset UPAKOVANO_PASSWORD
```

После запуска сервера откройте [http://127.0.0.1:3000/admin](http://127.0.0.1:3000/admin) и войдите с указанными данными. Не добавляйте настоящий пароль в код, README или Git.

## Проверки проекта

```sh
bin/rails test
bin/rails test:system
bin/rubocop
bundle exec brakeman --no-pager
bin/bundler-audit check
```

Основные тесты проверяют модели, фильтры, расчёт, безопасность публичных данных и административные операции. Системные тесты проходят полный пользовательский и редакторский сценарии. Дополнительно интерфейс вручную проверен в браузере на ширинах 1440, 1024, 768 и 375 px.

## Основные страницы

| Адрес | Назначение |
|---|---|
| `/` | Главная, подборки и быстрый расчёт |
| `/media` | Опубликованные материалы |
| `/categories/:slug` | Публикации категории |
| `/materials` | Каталог материалов |
| `/calculator` | Полный предварительный расчёт |
| `/suppliers` | Фильтруемый каталог компаний |
| `/inquiries/new` | Учебная заявка |
| `/about` | О проекте и его ограничениях |
| `/admin` | Защищённая панель управления |

Черновики, будущие публикации и неактивные поставщики не доступны в публичной части даже по прямой ссылке.

## Данные и устройство

Приложение — Rails-монолит с ERB, Turbo и небольшими Stimulus-контроллерами. Данные хранятся в SQLite.

```text
Category 1 ── * Post
Material * ── * Supplier   (через SupplierMaterial)
Material 1 ── * Inquiry
Supplier 0..1 ── * Inquiry
Subscription                  отдельный локальный список
Admin                         отдельная защищённая учётная запись
```

- `PackagingEstimator` содержит детерминированную формулу и не зависит от браузера.
- Контроллер заявки повторно рассчитывает цену на сервере: присланную пользователем сумму сохранить нельзя.
- Администратор может менять у заявки только статус; исходные параметры и расчёт остаются неизменными.
- Публичные подборки главной страницы загружаются из базы, а не хранятся массивами в шаблоне.
- Figma-иллюстрации сохранены локально в `app/assets/images/figma/`; временные ссылки не нужны для запуска.

## Ограничения калькулятора

Расчёт показывает ориентир для учебного сценария, а не коммерческое предложение. Эталонный набор параметров — коробка 90 × 90 × 110 мм, тираж 500, микрогофрокартон, Москва — даёт 24 ₽ за штуку. Итоговая цена в реальном заказе зависит от конструкции, печати, производства, логистики и требований поставщика.

## Демонстрация за 3–5 минут

1. Откройте главную и покажите три точки входа: материалы, расчёт и поставщики.
2. В быстром калькуляторе оставьте эталонные параметры и получите 24 ₽ за штуку. Подчеркните подпись о предварительном расчёте.
3. Перейдите к подходящим компаниям, отфильтруйте список и откройте карточку поставщика.
4. Создайте учебную заявку и покажите подтверждение, что она никуда не отправляется.
5. Откройте публикацию в «Медиа» и карточку материала с оценками «N из 5».
6. Войдите в `/admin`, создайте черновик публикации, опубликуйте его и покажите появление в публичной части.
7. Откройте заявку в админке и смените только её статус.

## Осознанно не входит в MVP

- реальные платежи, заказы, рассылки и интеграции с поставщиками;
- регистрация покупателей и личный кабинет с настоящей историей заказов;
- загрузка файлов и изображений через админку;
- роли нескольких редакторов и восстановление пароля;
- промышленное развёртывание, аналитика и юридические документы.

Проект подготовлен к размещению в Git-репозитории, но отправка в GitHub выполняется отдельно и только после явного решения владельца проекта.
